One original fortune-cookie line for a software developer, entered in
[make.fun's Fortune Cookie Wisdom for Developers bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

> The estimate was honest when you made it; the code changed its mind.

The line is 68 characters long. `main.py` is a stdlib-only copier: it copies
the pre-written `entry.txt` byte-for-byte into `MAKEFUN_OUTPUT_DIR`.

## How the line meets the judge's criteria, in order

1. **A fortune-cookie line, not a slogan or punchline.** It is written as a
   fortune — a small prophecy about your work — not as advice telling you
   what to do, and not as a joke with a punchline.
2. **Reads like a fortune cookie.** One short balanced sentence in two
   clauses, landing in a single breath: the honest estimate, then the code
   changing its mind.
3. **True about a developer's day.** Estimates slip; every developer has
   watched a careful estimate come undone once the code was actually written.
4. **A fresh turn, not a familiar saying.** It does not repeat "estimates are
   always wrong" or Hofstadter's law — it moves the blame off the estimator
   and onto the code itself.
5. **A quiet twist for a second read.** "The code changed its mind" gives the
   code a mind it does not have, and on a second read it absolves the person
   who estimated: the plan was honest, the work moved.
